A simple digital calculator built with HTML, CSS, and JavaScript.



## Description
This repository contains a digital calculator that performs basic arithmetic calculations. It provides a user-friendly interface for addition, subtraction, multiplication, division, square root, and cube root operations. The calculator is designed to be responsive and works well on both desktop and mobile devices.

## Features ✨
- **Basic Arithmetic Operations**: Perform addition, subtraction, multiplication, and division.
- **Advanced Functions**: Includes square root (√) and cube root (³√) calculations.
- **Clear Functionality**: Clears the display.
- **Delete Functionality**: Deletes the last entered character.
- **Responsive Design**: Optimized for both desktop and mobile views.
- **User-Friendly Interface**: Easy-to-use buttons with visual feedback.

## Installation ⚙️
1. Clone the repository:
   ```bash
   git clone https://github.com/Sonucs12/digital-calculator.git
   ```
2. Open `index.html` in your browser to view the calculator.



## Usage 💡
1.  Enter numbers and operators using the buttons on the calculator.
2.  Click '=' to evaluate the expression.
3.  Click 'Clear' to clear the display.
4.  Click 'DEL' to delete the last entered character.
5.  Click '√' to calculate the square root of the current number.
6.  Click '³√' to calculate the cube root of the current number.

**Example:**

To calculate the square root of 9:

1.  Enter `9`.
2.  Click `√`.
3.  The display will show `3`.
